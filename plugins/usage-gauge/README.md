# usage-gauge

## 概要

Claude Code の入力欄のすぐ上の帯に、使用量のゲージを並べる mod（関数フックのプラグイン）です。

| 項目 | ゲージの右に出るもの | 取得元 |
|------|------------------|--------|
| コンテキスト | 使用率、`401.9k/1M`（トークン数/ウィンドウ） | 公式 API（`$.session.usage()`） |
| 5時間 | 使用率、リセットまでの残り（`あと4時間12分`） | 公式 API（取れないときは非公式 API） |
| 週間 | 使用率、リセットまでの残り（`あと2日22時間`） | 公式 API（取れないときは非公式 API） |
| 週間 Fable | 使用率、リセットまでの残り | 非公式 API |
| クレジット | 使用率、`$0/$200`（使った額/月の上限） | 非公式 API |

- ゲージの色は、使用率 70% 未満が緑、70〜90% が黄、90% 以上が赤
- 時間枠のゲージ（5時間・週間・週間 Fable）には、枠の経過時間の位置に縦の目盛りが付く。目盛りより使用率が先に進んでいれば、このペースでは枠を使い切る
- 帯の幅が足りれば2列、狭ければ1列に並ぶ。アンケートが出ている間は帯を譲る
- デスクトップアプリでは細いバー（SVG）、ターミナルでは罫線の文字でゲージを描く

### 非公式 API とトークンについて

週間 Fable とクレジットは公式の mod API で取れないため、非公式の OAuth 使用量 API `GET https://api.anthropic.com/api/oauth/usage` を呼んでいます。

- 認証には `$.session.authorize()` を使います。Claude Code 本体がセッションのログイン情報（OAuth トークン）を持ったまま、リクエストに認証ヘッダーを付けます。mod にはトークンの値が渡らず、macOS Keychain も読みません
- 非公式 API は予告なく変わったり使えなくなったりします。取得に失敗すると帯の下に `非公式API取得失敗` と薄字で出し、前回取れた値（`$.store` に保存）を表示し続けます
- 呼び出しは最短 5 分おきに間引き、失敗が続くと間隔を 2 分から倍々に延ばします（上限 15 分）。短い間隔で呼ぶと 429 が返り続けるためです

## インストール

```bash
# マーケットプレイスを追加（初回のみ）
claude plugin marketplace add rfdnxbro/claude-code-marketplace

# プラグインをユーザースコープでインストール
claude plugin install usage-gauge@custom-marketplace
```

開いているセッションには `/reload-plugins` で読み込みます。

## 使い方

インストールすると、入力欄の上に使用量の帯が出ます。操作は不要です。

- 帯の左端の `▾` を押すと1行の要約（`ctx 40% · 5h 5% · 週 32% · Fable 4% · $0/$200`）に折りたたみ、`▸` で開きます。開閉の状態は次回起動にも持ち越します
- 公式値は各ターンの後と 1 分ごとに、残り時間の表示は 1 分ごとに更新します
- extra usage が無効なアカウントでは、クレジットは `$0 無効` と出ます

## 前提条件

- Claude Code の mod（関数フック）に対応したバージョン。2.1.309 で動作を確認しています
- 描画はターミナルとデスクトップアプリの Code タブ。VS Code 拡張とモバイルには入力欄上の帯が無いため表示されません
- Claude のサブスクリプションでログインしていること（API キーやゲートウェイ経由では、5時間・週間の枠と非公式 API が取れません）
