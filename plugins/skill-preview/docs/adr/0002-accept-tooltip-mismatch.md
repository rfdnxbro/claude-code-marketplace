# 0002 候補リストのツールチップと右ペインの文言のずれを受け入れる

- 状態: 決定（2026-11-04）

## 背景

[0001](0001-translate-in-pane-only.md) で、日本語訳は右ペインだけに出すことにした。Claude Desktop の候補リストは、公式訳のある組み込みコマンドには日本語を、それ以外のコマンドとスキル（`/compact`、`/init`、`anthropic-skills:pdf` など）には英語を出す。

## 決定

Desktop が公式訳を持たないコマンドとスキルでは、候補リストのツールチップは英語、右ペインは日本語（自前訳）、とずれることを受け入れる。

## 理由

- ツールチップはアプリが決める短い表示、右ペインは詳しく読むための場所、と役割が違う
- そろえるには候補リストの説明を書き換える必要があり、[0001](0001-translate-in-pane-only.md) で避けた影響（Claude に渡るスキル一覧が変わる）を受け入れることになる

## 影響

- README の「説明の日本語訳」に、ずれることを書く
- 公式訳のある組み込みコマンドでは、ツールチップと右ペインが同じ文言になる（[0004](0004-keep-official-labels.md)）
