# 0001 説明の日本語訳は右ペインだけに出す

- 状態: 決定（2026-11-04）

## 背景

skill-preview は、組み込み・Anthropic 提供のスキルとコマンドの説明を日本語にして表示する。当初は右ペインに加えて、入力欄の候補リストと `/help` にも訳を出すため、`command.describe` イベントで説明を書き換えていた。

Claude Desktop の Code タブ（内蔵の Claude Code 2.1.309）で試したところ、次のことが分かった。

- `command.describe` で書き換えた説明は、Claude がスキルを選ぶときに読むスキル一覧（セッションに渡る skills の一覧）の説明にも使われる。mod を読み込んだセッションでは、Claude に渡るスキルの説明が日本語訳に変わった
- Desktop の候補リストは、Desktop アプリが公式の日本語訳を持つ組み込みコマンド（42 件）には自分の文言を出し、mod の書き換えは届かない
- それ以外の候補（Desktop・ターミナル）に書き換えが届くかは確かめていない

Anthropic 提供のスキルの説明は、どんなときに起動するかを英語で細かく書いている（「トリガー」「スキップ」の条件など）。

## 決定

`command.describe` では説明を書き換えない。日本語訳は右ペインだけに出す。

`command.describe` は、説明を受け取るためだけに使う（`$.command.list()` に無い組み込みを右ペインで補い、未訳を数える）。

## 理由

- 候補リストの訳で得られるのは見た目の利点だけだが、スキル一覧の説明を変えると、すべてのセッションでスキルが正しく選ばれるかに影響しうる。訳は原文に忠実にしたが、選ばれる精度への影響は確かめられていない
- Desktop の候補リストの多く（公式訳のある 42 件）には、書き換えがもともと届かない
- 書き換えの処理と、その効き目を確かめる手間が要らなくなる

## 影響

- 入力欄の候補リストと `/help` の説明は元のまま（Desktop の公式訳のあるものは日本語、それ以外は英語）
- Claude に渡るスキル一覧は英語の原文のまま
- 候補リストのツールチップと右ペインの文言がずれるものが出る（[0002](0002-accept-tooltip-mismatch.md)）
