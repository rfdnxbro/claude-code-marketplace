# ja-reply-guard

## 概要

Claude の返答が勝手に英語だらけになったとき、日本語で返すよう促す mod です。どのモデルでも同じように判定します。

- **ターンの途中**: モデルのステップ（1回のリクエスト）が終わるたびに、そのターンでここまでに出た可視テキストを見ます。英語だらけで、まだツール呼び出しが続くときは、「以降の返答は日本語で書いてください。コード・コマンド・識別子は原文のままで構いません。」という行を会話に差し込みます。モデルは次のステップからこの行を読みます。差し込みは1ターンに1回までです
- **ターンの最後**: 最終回答が英語だらけなら、「直前の返答が英語になっていました。同じ内容を日本語で書き直してください。」という依頼を送ります。依頼はセッションが空いたら新しいターンとして始まります。書き直しの依頼は、人が次のプロンプトを送るまで1回までです（書き直しのターンも英語のままだったときに、依頼を繰り返さないため）
- 差し込んだときや書き直しを依頼したときは、トーストで短く知らせます

次の場合は何もしません。

- ユーザーが英語での返答を求めたとき（プロンプトに「英語で」「英訳」「英文で」「in English」のどれかを書いた、またはプロンプトを英語で書いた）
- 短い返答（地の文の英字が 80 文字未満）や、英単語が混じっているだけの日本語の返答
- サブエージェントのステップと回答
- 中断されたターン、拒否やエラーで終わったターン

mod は Claude Code のプロセス内で動く関数フックのプラグインです。仕組みは公式ドキュメント [Mods overview](https://code.claude.com/docs/en/plugins/mods/overview) を参照してください。

### 「英語だらけ」の判定

返答から次の部分を除いた残り（地の文）で判定します。

- コードブロック（` ``` ` や `~~~` の行で挟んだ部分）とインラインコード
- URL、ファイルパス、拡張子付きのファイル名
- `>` で始まる引用の行（ツール出力の貼り付けなど）

地の文の英字が 80 文字以上あり、日本語の文字（ひらがな・カタカナ・漢字）の割合（日本語の文字 ÷（日本語の文字＋英字））が 0.15 未満のときに「英語だらけ」とします。ターンの途中の判定では、そのターンで出たテキストを積み重ねて見るので、短い英語のつぶやきが続いたときも拾います。

プロンプトは、地の文に日本語の文字が 2 文字未満で英字が 20 文字以上なら「英語で書かれた」とみなします。日本語の依頼に英語のエラーログを貼ったものは日本語のプロンプトとして扱います。しきい値は `hooks/lang.ts` の定数にまとめています。

## 前提条件

- **Claude Code v2.1.309 以降**（mod の API は早期アクセスのため、バージョンによって動かない場合があります）
- ターミナル、Claude Desktop の Code タブ、VS Code 拡張で動きます。Desktop の WSL セッションでは動きません

## インストール

> **Note**: このプラグインは `.claude-plugin/marketplace.json` への登録が済むまで、以下の手順ではインストールできません。それまでは「開発」の手順で読み込んでください。

```bash
# マーケットプレイスを追加（初回のみ）
claude plugin marketplace add rfdnxbro/claude-code-marketplace

# プラグインをユーザースコープでインストール
claude plugin install ja-reply-guard@custom-marketplace
```

開いているセッションには `/reload-plugins` で読み込みます。

## 使い方

インストールすると、設定なしで常に動きます。返答が英語だらけになると、次のトーストが出ます。

| トースト | 意味 |
|---|---|
| 返答が英語になっていたので、日本語で書くよう指示しました | ターンの途中で、日本語で書くよう指示する行を差し込んだ |
| 返答が英語になっていたので、日本語での書き直しを依頼しました | ターンの最後に、書き直しの依頼を送った。次のターンで日本語の回答が返る |

英語での回答がほしいときは、プロンプトに「英語で答えて」「Answer in English」のように「英語で」「英訳」「英文で」「in English」のどれかを書くか、プロンプトを英語で書いてください。そのプロンプトの回答には反応しません。止めたいときは `/plugin` の Installed タブで無効にします。

## 制限

- 判定は、人が入力欄（または Remote Control、チャンネル）から最後に送ったプロンプトを基準にします。バックグラウンドタスクの通知や他のセッションからのメッセージで始まったターンは、直前の人のプロンプトで判定します
- 日本語の文字を含まない 20 文字以上の英語のプロンプト（例: `fix the failing test in auth`）は「英語で書かれた」とみなすため、その回答には反応しません。日本語で返してほしいときは、プロンプトに日本語を1語でも含めてください
- 「英語で」「in English」などはプロンプトのどこにあっても英語の指定とみなします（「英語で検索して」や、貼り付けたコード・引用の中の「英語で答えて」も含む）。そのプロンプトの回答には反応しません
- バックグラウンドタスクの通知などで始まったターンが続くと、人が次のプロンプトを送るまでは書き直しの依頼は1回だけです
- mod を読み込み直した直後のターン（始まりを見ていないターン）には、書き直しの依頼を送りません
- 書き直しの依頼は会話に「The ja-reply-guard plugin sent a message」として残り、その分のトークンを使います

## 開発

```bash
# 静的解析（Mod を動かす環境と同じバージョンの claude で実行する）
claude plugin validate plugins/ja-reply-guard

# テスト（hooks/lang.test.ts と hooks/register.test.ts）
claude plugin test plugins/ja-reply-guard

# 開発中のセッションに読み込む
claude --plugin-dir plugins/ja-reply-guard
```

`.claude-plugin/types/`（`claude-code` の型定義と、この mod の `tsconfig.json` が継承する設定）は、Claude Code がこの mod を読み込んだときに生成します。生成するコマンドは無く、`git` の管理対象外です（`.gitignore` で除外）。一度読み込んだあとは `tsc -p plugins/ja-reply-guard` で型チェックできます。
